DiscoVeR - Discover Virtual Reality

Transform 3D models into immersive browser-based VR environments using Unity WebGL technology

About Our Project

DiscoVeR is a full-stack, enterprise-grade web platform developed as a senior design project[cite: 35]. It enables users to easily upload, manage, and visualize 3D models through a completely interactive browser environment[cite: 36, 41]. The platform aims to democratize access to immersive digital spaces across multiple industries, professionals, and individual users[cite: 37, 254].

By integrating a robust Next.js frontend and NestJS backend with a web-optimized Unity WebGL graphics engine, our solution eliminates the need to download heavy standalone applications or configurations[cite: 38, 42, 67]. Everything executes dynamically over a secure web layout, opening the doors of interactive virtual navigation to anyone with a standard browser and an internet connection[cite: 38, 41].

Whether you are an individual wanting to freely explore distinct spatial experiences[cite: 255], a passionate architect looking to showcase structural house layouts to potential clients, or a real estate agent aiming to provide intuitive virtual house tours, DiscoVeR bridges the gap between complex 3D graphic data and high-performance, everyday web interaction.

Key Structural Features

🎯

Next.js 16 SPA Frontend

Built with React 19 and TypeScript, providing secure dashboard management, state protection, and smooth navigation layout[cite: 47, 53].

⚙️

NestJS 11 Backend API

Enterprise pattern backend with robust validation layer, integrated with a secure SQLite relational schema using Prisma ORM[cite: 58, 62, 99].

🥽

Unity WebGL Engine

Renders immersive virtual environments natively, leveraging browser graphics pipeline capability with embedded scripts[cite: 66, 73].

🔄

GLB Runtime Parsing

Dynamic runtime 3D asset extraction and loading through Javascript bridge calls directly handling efficient single-binary GLB buffers[cite: 68, 69].

🛡️

Rigid Security Architecture

Full JWT sessions, Double-Submit Cookie CSRF protection, Argon2 hashing, Helmet protection, and express rate-limiting controls[cite: 60, 65, 94].

⚡

Zero Installation Needed

Full responsive layout compatible across standard browsers (Chrome, Edge, Firefox) without hardware-locked installations[cite: 38, 153].

Key Industry & Individual Use Cases

🏠 Smart Real Estate (Emlakçılar)

Real estate agents can deliver interactive, browser-based virtual house tours (ev gezisi) to prospective buyers[cite: 259]. Clients can inspect room volumes, wander through properties remotely, and gain an immersive spatial understanding from anywhere in the world, saving immense travel coordination costs[cite: 259, 261].

🏢 Collaborative Architecture (Mimarlar)

Architects and designers can utilize the platform to perfectly showcase their newly constructed or planned house blueprints in full 3D[cite: 260]. By uploading optimized model configurations, they can present their layouts to stakeholders and clients, making design walkthroughs completely sensory and intuitive before physical building processes start[cite: 260, 265].

👤 Individual Exploration (Bireysel İnsanlar)

Independent users can freely navigate the platform to explore unique, interactive spaces directly within their standard web browsers[cite: 255]. Individual creators can preview their custom 3D environmental assets natively, experiencing full orbit, zoom, and panning freedoms without needing to launch heavy compilation programs[cite: 70, 83].

🏨 Hotel & Tourism Previews

Hotel managers and tourist businesses can display structural layout representations directly on viewer links[cite: 81, 259]. Prospective visitors can explore accommodations and common areas online, building early consumer confidence before finalizing their destination bookings[cite: 259].
